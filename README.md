## 🎯 Обзор проекта

Платформа **DevLearn** состоит из двух ключевых компонентов в едином репозитории:

1. **`api/`** — Высокопроизводительный REST API на Express 5 + SQLite (`better-sqlite3`). Отвечает за хранение карточек, базу вопросов (Junior / Middle / Senior), историю ревью и алгоритм интервального обучения (SRS).
2. **`mobile-app/`** — Единое кроссплатформенное приложение на **Expo 57 / React Native 0.86 (Android, iOS и Web)** в ярком стиле **Neo-Brutalism**. Включает интерактивного маскота **Dotty**, колоды карточек, спринт-блиц тренажер и мультиязычность (`ru` / `uz`).

> [!NOTE]
> Веб-версия приложения не требует отдельного фронтенда — она работает прямо из `mobile-app` через `react-native-web` (`npm run dev:web`), сохраняя 100% функционала, анимаций и стиля.

### 🧠 Алгоритм интервальных повторений (SRS)
В бэкенде реализован алгоритм интервального запоминания (модифицированный SuperMemo SM-2):
- При правильном ответе интервал повторения увеличивается экспоненциально (`interval = interval === 0 ? 1 : interval * 2`), а дата следующего повторения (`next_review_at`) сдвигается в будущее.
- При ошибке интервал сбрасывается (`interval = 0`), карточка возвращается в активный пул для немедленного закрепления.
- Эндпоинт `/api/cards/due` возвращает только те карточки, которые требуют повторения прямо сейчас.

### 🎨 Дизайн-система Neo-Brutalism
- **Контрастные границы**: жесткие черные рамки `border: 2-3px #000`.
- **Жесткие оффсет-тени**: `4px 4px 0px #000` без размытия (hard offset shadow).
- **Палитра**:
  - Желтый `#FFE600`
  - Неоновый зеленый `#00FF66`
  - Электрический голубой `#00F0FF`
  - Огненный оранжевый `#FF5C00`
  - Розовый `#FF0055`
- **Маскот Dotty**: интерактивный персонаж, реагирующий на нажатия физической spring-анимацией и дающий подсказки по разработке.

## 📦 Библиотеки и зависимости

### 1. Корневой воркспейс (`/`)
* **`concurrently`** (`^9.2.4`) — одновременный запуск API и приложения с цветными логами в одном терминале.

### 2. Backend (`api/package.json`)
* **`express`** (`^5.2.1`) — быстрый HTTP-фреймворк для реализации REST API.
* **`better-sqlite3`** (`^13.0.3`) — самый производительный синхронный драйвер SQLite для Node.js.
* **`cors`** (`^2.8.6`) — middleware для доступа клиентских приложений к API.
* **`dotenv`** (`^17.4.2`) — управление переменными окружения.
* **`jsonwebtoken`** (`^9.0.3`) & **`bcryptjs`** (`^3.0.3`) — криптография, хэширование и JWT-токены.

### 3. Cross-platform App (`mobile-app/package.json`)
* **`expo`** (`~57.0.20`) — основа кроссплатформенной инфраструктуры.
* **`react-native`** (`0.86.3`) — ядро мобильной разработки.
* **`react-native-web`** (`^0.21.2`) — рендеринг React Native компонентов в браузере (для `npm run dev:web`).
* **`react-native-svg`** (`15.15.4`) — отрисовка векторной графики.
* **`@expo/vector-icons`** (`^15.0.2`) — векторные иконки Feather.
* **`expo-status-bar`** (`~57.0.1`) — стилизация статус-бара устройства.
* **`@expo/metro-runtime`** (`~57.0.15`) — поддержка быстрого Fast Refresh.
* **`@expo/ngrok`** (`^4.1.3`) — тоннели для тестирования на реальных смартфонах.
* **`qrcode-terminal`** (`^0.12.0`) — генерация QR-кода Expo в консоли.

## 🔍 Детальное описание модулей

### 1. `api/server.js`
- **Категории вопросов**: `Node.js`, `Nest.js`, `Express`, `React`, `Nginx`, `Linux`, `English`.
- **Таблицы**:
  - `cards`: утверждения, булевы ответы, объяснения (`punchline`), параметры SRS-интервалов.
  - `reviews_history`: аудит ответов для расчета статистики и ударного режима (streak).
- **Эндпоинты**:
  - `GET /api/cards?category=:cat` — список карточек по выбранной категории.
  - `GET /api/cards/due` — карточки, подошедшие по времени для повторения.
  - `POST /api/cards/:id/answer` — отправка ответа и перерасчет даты следующего ревью.
  - `GET /api/stats` — общая аналитика обучения.

### 2. `mobile-app/App.js` и экраны
- **Мультиязычность**: переключение между `ru` и `uz` в один клик с плавной анимацией и тоастом.
- **Интерактивный Dotty**: баунс-анимация прыжка (`Animated.spring`) и динамические речевые баблы с советами.
- **Спринт-блиц (`BlitzScreen`)**: тайм-атака с комбо-множителями и подсчетом рекордов.
- **Оффлайн-режим**: все вопросы и наборы карточек вшиты в константы, приложение полностью автономно при отсутствии сети.

## 🚀 Установка и запуск

### 1. Установка всех зависимостей:
```bash
npm run install:all
```

---

### 2. Запуск проекта:

* **Запуск API + Мобильного приложения одновременно (Рекомендуется):**
  ```bash
  npm run dev
  ```
  *(Поднимет API на порту 3001 и запустит Metro bundler для телефона).*

* **Запуск в браузере (Web-версия через Expo):**
  ```bash
  npm run dev:web
  ```

* **Запуск только API:**
  ```bash
  npm run dev:api
  ```

* **Запуск только приложения (Expo):**
  ```bash
  npm run dev:mobile
  ```

* **Запуск мобильного приложения с тоннелем (`--tunnel` для Expo Go через интернет):**
  ```bash
  # Интерактивный запуск из корня проекта:
  npm run dev:mobile:tunnel
  # Или запуск из директории mobile-app:
  cd mobile-app && npm run tunnel

  # Запуск в оптимизированном продакшн-режиме:
  npm run tunnel:prod
  ```

## 🔧 Решение проблем (Ubuntu 24.04 / Electron)

Если `expo start` падает с `FATAL:setuid_sandbox_host.cc` или `Signal: 5 (TRAP)`:

1. **Системное решение (один раз на уровне ядра)**:
   ```bash
   echo "kernel.apparmor_restrict_unprivileged_userns = 0" | sudo tee /etc/sysctl.d/20-apparmor-donotrestrict.conf
   sudo sysctl --system
   ```
2. **Либо запуск с переменной**:
   ```bash
   ELECTRON_DISABLE_SANDBOX=1 npm run dev
   ```
